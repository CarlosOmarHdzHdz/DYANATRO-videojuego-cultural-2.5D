# Ludoteca digital

Módulo autónomo de consulta y práctica integrado en DYANATR’O. La carpeta
reúne la interfaz, los tres minijuegos, sus imágenes, el importador y las pruebas.

| Carpeta | Contenido |
| --- | --- |
| `Runtime/` | Navegación, galería, fauna y minijuegos. Los archivos parciales comparten `XunjuuLudotecaBrowser`. |
| `Resources/Ludoteca/Gallery/` | Fotografías de la galería con atribución en `Documentation/`. |
| `Resources/Ludoteca/Icons/` | Atlas de iconos de navegación y elementos culturales. |
| `Resources/Ludoteca/Minigames/` | Motivos textiles del memorama y sol de finalización. |
| `Editor/Importers/` | Reglas de importación de las texturas de la ludoteca. |
| `Editor/Validation/` | Prueba automatizada de navegación y minijuegos en Play Mode. |
| `Documentation/` | Créditos de imágenes y descripción funcional. |

Los archivos `.meta` originales se conservaron al trasladar el módulo. Ejecuta
`Tools > Xunjuu > Validar minijuegos` en Unity para comprobar interacciones,
las tres etapas del memorama, la sopa, el quiz y sus mensajes de finalización.

El vocabulario mostrado sigue siendo demostrativo y requiere validación
lingüística y comunitaria antes de la publicación.
