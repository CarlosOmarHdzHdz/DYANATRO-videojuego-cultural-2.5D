# DYANATRO: Prototipo de videojuego cultural en 2.5D

Proyecto desarrollado en Unity como prototipo de videojuego cultural en perspectiva 2.5D, orientado a la preservacion y difusion de la cultura mazahua mediante exploracion, misiones, objetos coleccionables, inventario y combate.

## Requisitos de desarrollo

- Unity 6.3 LTS, version `6000.3.11f1`.
- Visual Studio Community con soporte para C#.
- Sistema operativo Windows 10 u 11 de 64 bits.

## Estructura principal

- `Assets/`: escenas, scripts, prefabs, sprites, audio, materiales y recursos del videojuego.
- `Packages/`: dependencias del proyecto Unity.
- `ProjectSettings/`: configuracion necesaria para abrir el proyecto en Unity.

## Escena principal

- `Assets/Scenes/SampleScene.unity`

## Notas

Este repositorio contiene unicamente los archivos del videojuego. Se excluyen documentos academicos del anteproyecto, archivos PDF, Word, presentaciones, builds generados, cache de Unity y carpetas temporales.
